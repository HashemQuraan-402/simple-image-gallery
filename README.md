# Simple Image Gallery

A responsive image gallery built with HTML, CSS, and vanilla JavaScript. It generates thumbnail elements dynamically and lets users change the featured image through click, hover, focus, or keyboard interaction.

## Features

- Dynamically generated thumbnail rows
- Click-based image selection in the upper row
- Hover-based image preview in the lower row
- Keyboard-accessible thumbnail selection
- Responsive image sizing for desktop, tablet, and mobile layouts
- Smooth hover and focus feedback

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

No installation or build step is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/HashemQuraan-402/Simple-Gallary.git
   ```

2. Open the cloned folder.
3. Open `index.html` in a modern browser, or use the Live Server extension in Visual Studio Code.

## Current Scope

The gallery is a front-end DOM exercise. Images are bundled with the project, and there is no upload service, database, authentication, or back-end API.
